<h1 align="center">Zebra</h1>

<p align="center">iRacing overlay: fuel and refuel, relative, standings, speeds and wind.</p>

This repository holds the Zebra installers and the update manifest only (no source code).

## Install

1. Open the [latest release](https://github.com/otaviosoares/zebra-releases/releases/latest) and download `Zebra_<version>_x64-setup.exe`.
2. Run it. It installs for your Windows user only (no admin prompt).
3. If Windows shows "Windows protected your PC", click **More info → Run anyway** (the installer is not code-signed).

Zebra updates itself from here: it downloads new versions in the background and never installs while you are driving.
